# Real-Time-Public-Transport-Tracking-System 🚌

A modern, real-time GPS tracking system for public transportation. This application provides a seamless experience for users to track buses, view routes, and book tickets with a premium, responsive interface.


## 🌟 Features

- **Real-Time GPS Tracking**: Track bus locations live on an interactive map powered by Leaflet.js.
- **Multi-Role Access**: Dedicated login systems for **Users**, **Drivers**, and **Admins**.
- **Interactive Routes**: Explore 5+ active bus routes with detailed stop information.
- **Ticket Booking**: Integrated seat selection and booking system for commuters.
- **Service Alerts**: Stay updated with live arrival times and service notifications.
- **Responsive Design**: Premium dark-mode aesthetic with glassmorphism effects, optimized for all devices.
- **User Feedback**: Rate your journey and provide feedback directly through the app.

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Maps**: [Leaflet.js](https://leafletjs.com/) for interactive map rendering.
- **Icons**: [Font Awesome 6](https://fontawesome.com/)
- **Typography**: [Google Fonts (Inter)](https://fonts.google.com/specimen/Inter)
- **Styling**: Modern CSS features including Flexbox, Grid, and Custom Variables.

## 🚀 Getting Started

### Prerequisites
To run this project locally, you just need a modern web browser.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/ShantanuJais00/Real-Time-Public-Transport-Tracking-System.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Real-Time-Public-Transport-Tracking-System
   ```
3. Open `index.html` in your browser.
